## 🌐 Cara Membuat Link Online Gratis untuk CV (Vercel / GitHub Pages)

Agar link web ini bisa ditaruh di CV kamu (seperti milik temanmu `portofolio-velisa.vercel.app`), kamu bisa menggunakan **Vercel** atau **GitHub Pages** (gratis selamanya):

### Pilihan 1: Deploy Lewat Vercel (Paling Cepat & Populer)
1. Buka [vercel.com](https://vercel.com) lalu login dengan akun GitHub kamu (`Sabrinaharumie187`).
2. Buat repository baru di GitHub kamu, misalnya bernama `portofolio-sabrina`.
3. Unggah semua file di folder ini ke repository tersebut.
4. Di dashboard Vercel, klik **"Add New Project"** > pilih repository `portofolio-sabrina` > klik **Deploy**.
5. Dalam 1 menit, web kamu sudah online dengan alamat seperti `https://sabrina-harumie.vercel.app` yang siap dicantumkan di CV!

### Pilihan 2: Deploy Lewat GitHub Pages (Langsung dari GitHub)
1. Buat repository baru di GitHub bernama `sabrina-portfolio` atau `Sabrinaharumie187.github.io`.
2. Push semua file di folder ini.
3. Buka tab **Settings** di repository GitHub > pilih menu **Pages** di sebelah kiri.
4. Pada bagian *Branch*, pilih `main` dan klik **Save**.
5. Web kamu akan otomatis online di `https://Sabrinaharumie187.github.io`!
